# 网关职责边界

本仓库提供微信接入网关，不负责具体业务处理和模型调用。

网关职责：

- 完成 iLink 二维码登录、绑定凭据保存和长轮询维护。
- 接收微信文本、图片、语音等消息。
- 对媒体完成协议所需的 CDN 下载、解密和本地临时保存。
- 通过 Gin 本地 API 或消息事件向上层业务提供标准化消息。

业务层职责：

- 决定是否调用模型、调用哪个模型以及如何组织上下文。
- 决定图片和语音的识别、转写、存储和回复策略。
- 决定如何调用网关的发送接口回复微信。

媒体入站接口不得依赖模型配置、模型 API Key 或 SSE 客户端。当前阶段消息先输出 iLink 媒体元数据；CDN 解密和本地文件落盘作为后续网关能力补齐。
